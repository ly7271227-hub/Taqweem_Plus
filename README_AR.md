# تقويم بلس — مشروع Flutter

تطبيق عربي RTL يجمع التقويم الميلادي والهجري مع أدوات يومية وألعاب خفيفة.

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `takweem_plus_flutter` في Android Studio أو VS Code.
3. تأكد من تثبيت Flutter و Android SDK.
4. نفّذ:
   - `flutter pub get`
   - `flutter run`
5. لبناء APK:
   - `flutter build apk --release`
   ستجد الملف غالباً في `build/app/outputs/flutter-apk/app-release.apk`.

## محتويات النسخة
- لوحة رئيسية تعرض التاريخين.
- محول تاريخ ميلادي/هجري.
- حاسبة العمر، فرق الأيام، العد التنازلي، إضافة مدة لتاريخ.
- قائمة أدوات وألعاب صغيرة.
- لعبة أسئلة عامة ولعبة تحدي النقر.
- حفظ الاسم/الملاحظات محلياً باستخدام SharedPreferences.

## ملاحظات مهمة
- التاريخ الهجري يعتمد على مكتبة Hijri وقد يختلف يومًا حسب البلد والرؤية الشرعية.
- هذه نسخة أولية عملية قابلة للتطوير. بعض الأدوات مثل مواقيت الصلاة والطقس تحتاج ربط خدمة موثوقة ومفتاح API/تحديد مدينة، لذلك لا تعرض بيانات وهمية.
- لا يوجد تسجيل دخول ولا خادم خارجي.
